# Demo catalogue photography

These local photographs are provided for the demo shops, menu items, and product cards. They are illustrative and are not official photographs or endorsements from the named businesses.

The accompanying `sources.json` records the image source, author, landing page, and applicable free license for each image. The selected sources permit commercial reuse under CC BY, CC BY-SA, CC0, or the public-domain mark. Preserve the attribution information with these files.

`peanuts.jpg` is an alias of the credited peanut brittle photo, kept for compatibility with older image URLs.

Run `npm run db:photos` to fill only missing image URLs in an existing development database. New demo data uses the same local catalogue photos automatically.
